# CRP Luz — Landing Page Institucional

Landing page oficial e institucional da **CRP Luz (Companhia Rio Preto Luz)**, concessionária de iluminação pública de São José do Rio Preto — SP.

## 🚀 Tecnologias
- **HTML5 Semântico** (acessibilidade, tags de chamada direta 	el:08009214477, meta tags SEO e Open Graph)
- **CSS3 Moderno** (design responsivo, CSS Grid editorial assimétrico, Flexbox, glassmorphism e iluminação urbana com gradientes)
- **JavaScript (ES6+) Vanilla** (zero dependências externas, microparallax do vídeo no hero, light cursor interativo e controle dinâmico do header)

## 🛠️ Como Executar Localmente
Como o projeto é 100% estático (zero dependências ou etapas de build), basta abrir o index.html em qualquer navegador ou servir localmente:

`ash
# Com Python 3
python -m http.server 8080
`
Acesse em http://localhost:8080.
